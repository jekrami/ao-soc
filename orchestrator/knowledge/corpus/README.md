# Knowledge corpus

Markdown procedures, approved-tool lists and change windows indexed by LightRAG
when `KNOWLEDGE_ENABLED=true` and `KNOWLEDGE_DIR` points here (or to a site
directory with the same layout).

These files are **cited context** for the Tier-2 analyst prompt. They never
open or close the autopilot gate — that stays with `precedent.py`.

Each file receives a stable `DOC-…` id from its path (for example
`containment-endpoint.md` → `DOC-CONTAINMENT-ENDPOINT`).
